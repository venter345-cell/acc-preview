Add Ruben to your website

Your website is a custom built site, made with code (React). It is hosted at Afrihost. It does not use WordPress or Wix, so there is no "add user" page inside the site. The easy way is to add Ruben as a team user in your hosting control panel, called cPanel.

Ruben@acreationc.com
Open my cPanel Or log in through Afrihost ClientZone
Someone else built your site? That is very common. Just tell us who built it and how to reach them in step 3. With your OK, we will ask them for access and the site files.

How to do it

  1. Log in to cPanel. Or log in to Afrihost ClientZone, tap Hosting, pick clinotrend-health.co.za, then Website Manager.
  2. Find Preferences, then tap Manage Team.
  3. Tap Create Team User. For username, type ruben.
  4. Pick The user will set the account password. For contact email, type Ruben@acreationc.com.
  5. Under Roles, pick Web. Under Services, switch on File Transfer Protocol (FTP).
  6. Tick the security box, then tap Create. Ruben gets an email to set his own password.
